# حسابداری یما

اپلیکیشن اندرویدی حسابداری آفلاین برای نمایندگی تیل‌فروشی حاجی نواب پروانی.

## ساخت APK
در GitHub به بخش Actions بروید و workflow با نام **Build YEMA Android APK** را اجرا کنید. پس از موفقیت، artifact با نام **YEMA-ACCOUNTING-APK** را دریافت کنید.

## وضعیت نسخه فعلی
نسخه پایه شامل ثبت فروش، خرید عمده، موجودی پنج محصول، حساب مشتریان، مصارف و گزارش‌های اولیه است. این هنوز نسخه نهایی ۴۱ صفحه‌ای نیست. چاپ رسید، نرخ خودکار ارز، پشتیبان‌گیری، FIFO دقیق و تکمیل صفحات بعدی نیازمند توسعه و آزمایش بیشتر است.
